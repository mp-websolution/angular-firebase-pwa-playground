# Project ADRs

The decisions of this Project, one file per decision, named `NNNN-slug.md`. They are numbered from `0001` on their own, apart from the Baseline ADRs in `docs/adr/`, so a new Baseline ADR never collides with one here. Call them "Project ADR 0001" where a bare number could mean either.

This folder is Project-owned: the Template ships it with only this file, and the Project adds its ADRs here, never to `docs/adr/`.
