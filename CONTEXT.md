# Angular Firebase PWA Playground

A template repository for trying out Angular and Firebase updates and for prototyping ideas for future PWA projects.

## Language

**Playground**:
This repository as a whole: the Baseline plus any Prototypes, published as a GitHub template for future PWA projects.
_Avoid_: Starter, boilerplate, sandbox

**Baseline**:
The shell every future project inherits: authentication, the user profile, Firebase wiring, PWA behaviour, and the build and deploy pipeline.
_Avoid_: Core, skeleton, scaffold

**Prototype**:
A self-contained feature that sits beside the Baseline and can be deleted without changing the Baseline.
_Avoid_: Experiment, demo, module, feature (when the self-contained sense is meant)
